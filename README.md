# 3D Birthday Surprise Website

## Run
Open `index.html` in Chrome/Edge/Firefox.

## Customize
Open `script.js` and change:
- `personName`
- `birthday.day`
- `birthday.month`
- `letterText`

## Photos
The current version does not require photos. You can extend the letter screen with a gallery.

## Music
Put your own legally obtained MP3 at:
`assets/music.mp3`

Then tap the music button.

## Publish for free
Upload the folder to GitHub and enable GitHub Pages, or use another static hosting service.
